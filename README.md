## 作业目录

- `week1`：环境熟悉与 C++ 简单程序设计。共24个独立项目，包括2个环境示例、14个课堂示例和8道编程作业。兔子题放在本周，按教师更正要求使用循环和变量替换。
- `week2`：函数的定义、调用与调试。共12个正常项目和6个单独存放的诊断示例，绝对值重载已按教师要求命名为 `myabs`。

[第一周独立源码](week1/src/) · [第二周独立源码](week2/src/)

## 在 Visual Studio 中运行

1. 分别打开 `week1/VisualStudio项目/第一周_环境与简单程序设计.sln` 或 `week2/VisualStudio项目/函数实验_12题.sln`。
2. 选择 `Debug | x64`，右键需要运行的项目，选择“设为启动项目”。每个项目只有一个 `main`，不要把所有题的源码放进同一个项目生成。
3. 按 `Ctrl+F5` 生成并运行；需要输入的题目，可按该项目 `input.txt` 中的样例手动输入。设置断点后用 `F5` 启动，`F10` 逐过程，`F11` 逐语句进入函数。

项目使用 Visual Studio 2026、MSVC v145（工具版本14.51.36231）、Windows SDK 10.0、C++17 和 UTF-8。仓库不包含个人 `.vcxproj.user` 调试配置。

## 结果文件

`cli_sample_output.txt` 是实际 MSVC 命令行验证时保存的标准输出，不是 Visual Studio 界面截图。若项目附有 `output.txt`，它是另行在 Visual Studio 中运行后保存的标准输出文件；编辑器中打开该文件也不等同于实时控制台画面。输入输出重定向属于个人调试设置，未随项目上传。

第二周的 `diagnostics` 目录是独立反例：其中5个项目预期编译失败，另1个用于观察浮点数转整数的警告。它们不在12题正常程序的总解决方案中。
