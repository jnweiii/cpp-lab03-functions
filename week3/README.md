## 源码和项目

`projects`中的汇总解决方案只包含6个正常项目，也可以分别打开每题自己的`.sln`。

1. `01_Ctype_static`：普通成员和静态数据成员，分别观察各对象的a和共用的s。
2. `02_Student_counter`：依次创建4个Student对象，观察对象编号和累计创建数。
3. `03_Static_function`：通过类名和对象调用静态成员函数。
4. `04_Scope_5_3`：比较全局变量与同名局部变量的作用域。
5. `05_Cat_5_7`：通过构造、复制构造、赋值和析构检查存活对象数。
6. `06_Friends_5_13`：使用友元成员函数、友元类和全局友元函数访问私有成员。

另有`projects/diagnostics/Static_access_invalid`，专门验证静态成员函数不能直接访问普通成员。该项目应编译失败，与正常项目分开。

项目使用Visual Studio、Debug/x64、C++17、UTF-8、MSVC v145和Windows SDK 10.0.26100.0。所有题目使用代码中固定的数据，无须键盘输入。

每个正常项目的`output.txt`是本次从Visual Studio实际运行后保存的标准输出。仓库不包含机器专用的调试配置；下载后可生成项目并按Ctrl+F5在控制台查看结果。已有`output.txt`用于对照，不会自动更新。
